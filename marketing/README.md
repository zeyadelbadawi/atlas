# Atlas marketing

Marketing material for Atlas (أطلس), B1 launch (20 Oct 2026). The live
marketing **website** is code in `src/marketing/`; this folder holds
everything around it.

> **Prepared only.** Nothing here is posted, scheduled, sent or run as an ad
> before the owner's launch go-ahead and per-item approval. Arabic copy is
> Egyptian colloquial and has not had a native review yet (RV-14).

## Contents

| Path | What it is |
|---|---|
| `launch-kits/INDEX.md` | Start here: what is in both kits, claims register (CL-01…CL-25), required disclosures, screenshot status, open owner decisions (OD-01…OD-18) |
| `launch-kits/social-kit/` | Strategy and voice guide, launch calendar, 33 Facebook/Instagram posts, 14 short-video scripts, WhatsApp and teacher-group messages, LinkedIn posts, ad variants (**not to run before launch**), visual briefs |

## Rules that apply to every piece

- Prices come from the live catalog; any price written here is marked
  "[check live price at launch]".
- Never: the word "free" / «مجاني», protection or watermark claims, mobile
  app, live classes, card/Fawry checkout, testimonials or invented numbers,
  competitor names. See `site-spec/B1-SPEC.md` §A.10–A.12.
- Screenshots are real captures, never mirrored or edited inside the UI.

Some links inside these documents point to the private planning package
(`atlas-planning/…`); those files are not in this repository.
