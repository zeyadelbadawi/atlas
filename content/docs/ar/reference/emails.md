الإيميلات بتتكتب باللغة اللي كل شخص بيختارها من **لغة البريد الإلكتروني** في تفضيلات البريد بتاعته. وأحداث كتير بتظهر كمان في الإشعارات جوه المنصة.

## إيميلات الحساب والأمان (لكل الناس)

بتتبعت دايمًا ومش هتقدر توقفها.

- تأكيد الإيميل، وأكواد الدخول لما تدخل من جهاز جديد.
- روابط إعادة تعيين كلمة السر، وتأكيد بعد ما تغيّرها.
- تشغيل أو إيقاف المصادقة الثنائية، أو ربط أو فك طريقة دخول.
- حسابك انضم لأكاديمية جديدة.
- دعوة إنك تنضم لأكاديمية، كعضو في الفريق أو كمتعلم.
- أكواد وتحديثات طلب الخصوصية (نسخة من بياناتك أو حذف الحساب).

## إيميلات المتعلمين

| الإيميل | ينفع يتوقف؟ |
|---|---|
| إثبات الدفع بتاعك وصل | لا |
| الدفع بتاعك اتوافق عليه أو اترفض | لا |
| اتسجلت في دورة (أو سجلت فيها بنفسك)، أو تسجيلك اتشال، أو تاريخ انتهائه اتغير | لا |
| طلب انضمامك اتوافق عليه أو اترفض، أو دخولك اتمنع أو اترجع | لا |
| اتضفت للأكاديمية | لا |
| شهادة اتصدرت أو اتلغت | لا |
| جهاز اتشال من حسابك | لا |
| اختبار أو واجب اتصحح | آه |
| اختبار اتسلّم تلقائيًا، أو محاولة اتلغت | آه |
| استثناء في اختبار اتدّى لك أو بدأ أو اتشال | آه |
| خلّصت دورة | آه |
| رسالة من أكاديميتك (**الرسائل**) | آه |

الإعلانات بتظهر في إشعارات المتعلم، مش بالإيميل.

## إيميلات المالكين والفرق

| الإيميل | ينفع يتوقف؟ |
|---|---|
| أكاديميتك جاهزة، أو تجهيزها فشل | لا |
| متعلم بعت إثبات دفع للمراجعة | لا |
| اتضفت لفريق أكاديمية | لا |
| الفترة التجريبية بدأت، الاشتراك اتفعّل، دفعة خطتك وصلت أو اتوافق عليها أو اترفضت | لا |
| الإلغاء اتجدول، أو إشعار بتغيير السعر | لا |
| قرّبت من حد في خطتك أو وصلت له | لا |
| رد على تذكرة الدعم بتاعتك | آه |
| متعلمين مستنيين موافقة، تقييمات جديدة للدورات، رسائل التواصل من الموقع | بتتجمع في ملخّص يومي |
| تحديثات طلبات خدمات أطلس | بعضها ينفع يتوقف |

## إيه اللي تقدر توقفه

افتح تفضيلات البريد ووقّف الفئة اللي مش عايزها، أو اختار الملخّص اليومي لو متاح. تنبيهات الأمان والإيصالات وتغييرات الحساب بتفضل شغالة، وبيظهر عليها **مفعّل دائمًا**. شوف [تفضيلات البريد وإلغاء الاشتراك](doc:DOC-MSG-002).

## الإيميل ده فعلًا من أطلس؟

- ماتبعتش كلمة السر أو كود الدخول لأي حد، حتى لو قال إنه من أطلس أو من أكاديميتك.
- اكتب كود الدخول في صفحة الدخول اللي انت فاتحها بنفسك بس.
- لو وصلك إيميل عن تسجيل دخول أو تغيير كلمة سر أو أكاديمية جديدة وانت ماعملتش كده، غيّر كلمة السر فورًا. شوف [غيّر كلمة السر أو اعمل لها إعادة تعيين](doc:DOC-IAM-003).

> [!LIMITATION]
> أطلس بيبعت إيميلات وإشعارات جوه المنصة بس. مش بيبعت رسائل SMS أو واتساب.

الإيميل ماوصلكش؟ شوف [ماوصلنيش إيميل](doc:DOC-TRB-009).
