## Signing in

| Message | What it means | What to do |
|---|---|---|
| Invalid email or password. | The email or the password is wrong. | Check both, or reset your password. See [I can't sign in](doc:DOC-TRB-002). |
| You are a student. Please sign in through your academy’s website. | Learners can't sign in to the Atlas dashboard. | Open your academy's site and sign in there. See [Where to sign in](doc:DOC-IAM-002). |
| You are not a member of this academy yet. | Your account exists but hasn't joined this academy. | Sign up on the academy's site with the same email. See [A learner can't join the academy](doc:DOC-TRB-014). |
| Your access to this academy has been blocked. Please contact the academy. | The academy blocked this account. | Only the academy can unblock you. Contact them. |
| Too many attempts. Please wait a few minutes and try again. | Too many tries in a short time. | Wait a few minutes, then try again. |
| That code didn't work. Check the latest email and try again. | The sign-in code is wrong or is not the newest one. | Use the code from the most recent email. See [Sign-in codes by email](doc:DOC-IAM-005). |
| That code has expired. Request a new one. | Sign-in codes are valid for a short time only. | Ask for a new code. |
| Too many wrong codes. Please sign in again. | The code was entered wrong too many times. | Start signing in again to get a new code. |
| We can't deliver email to this address right now. | Emails to this address are bouncing or blocked. | Check the address, or see [I didn't get an email](doc:DOC-TRB-009). |

## Learning and videos

| Message | What it means | What to do |
|---|---|---|
| You are already learning on the maximum number of devices allowed. … | This browser would be one device too many. | Remove a device you no longer use. See ["Device limit reached"](doc:DOC-TRB-003). |
| You are already learning on another device. … | Only a limited number of learning sessions can run at once. | Continue here to end the other session, or go back to the other device. |
| This lesson has no content yet. The academy has not added anything to it. | The lesson is empty or uses a type that can't be shown. | Learners: tell the academy. Owners: add a YouTube or link lesson. See [A lesson won't open or play](doc:DOC-TRB-004). |
| Finish the earlier lessons in this course first. … | The course opens lessons in order. | Complete the previous item first. |
| This lesson has not opened yet. … | The academy scheduled the lesson for a later date. | Come back on that date. |
| Your access to this course has ended, so its content can no longer be opened. … | The enrollment has ended or was removed. | Contact the academy if this is a mistake. |
| This video couldn’t be prepared securely right now. Please try again in a moment. | The protected video could not be prepared. | Wait a moment and reload. |
| You are opening content faster than we can check your access. … | Too many lessons opened in a short time. | Wait a moment, then try again. |

## Plans and subscriptions

| Message | What it means | What to do |
|---|---|---|
| You've reached your plan's limit for this. Upgrade your plan to continue. | Adding this would go over a plan limit. Nothing was deleted. | Upgrade, or remove items you no longer need. See [You've reached a plan limit](doc:DOC-TRB-010). |
| Your subscription isn't currently active. Renew or upgrade your plan to continue. | Your trial or subscription has ended. | Choose a plan and pay. See [The dashboard is read-only](doc:DOC-TRB-015). |
| An active subscription is required to make this change. | Changes need an active plan. | Same as above. |

## Editing courses and pages

| Message | What it means | What to do |
|---|---|---|
| Learners already have progress, attempts or submissions for this item, so it can't be deleted … | Deleting would erase learners' records. | Set the item to draft instead. See [Can't delete a lesson, quiz or section](doc:DOC-TRB-012). |
| This content was changed by someone else while you were editing. | Someone saved a newer version first. | Reload and make your change again. See [Website save conflict](doc:DOC-TRB-013). |

## Payments

| Message | What it means | What to do |
|---|---|---|
| A payment for this order is already being reviewed by the academy. … | The learner already sent a proof. | Wait for the email with the decision. See [Payment proof pending or rejected](doc:DOC-TRB-008). |
| This order was paid to the academy directly. Contact the academy about a refund. | The money went to the academy, so Atlas can't refund it. | Ask the academy. See [Refunds for course purchases](doc:DOC-COM-005). |
| This payment is no longer waiting for review. Reload to see its current status. | Someone already approved or rejected it. | Reload the page. |
| This order has expired. Start a new order to buy the course. | The order's payment window passed before a payment was sent. | Open the course again and buy it again. |
| Upload the payment proof as a PNG, JPEG or PDF file. | The proof file is another type. | Take a screenshot or save the receipt as PDF, then upload it. See [Payment proof pending or rejected](doc:DOC-TRB-008). |

## Academy setup

| Message | What it means | What to do |
|---|---|---|
| This address is already taken. Please choose another one. | Another academy uses that subdomain. | Pick a different address. |
| Something went wrong while setting up your Academy. … | A setup step failed. | Try again, or see [Academy creation is stuck or failed](doc:DOC-TRB-007). |
