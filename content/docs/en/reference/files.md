## Upload limits by place

| Where | Accepted files | Maximum size |
|---|---|---|
| Academy media library | JPEG, PNG, GIF, WebP images and PDF | Not shown in advance: a file that is too big gets "That file is too large to upload." |
| Lesson file (in the course builder) | PDF or image | 20 MB |
| Logo (**Visual Identity**) | PNG, JPG, WebP or SVG | 2 MB |
| Favicon | PNG or ICO | 1 MB |
| Course thumbnail | PNG or JPG | 5 MB |
| Payment proof for a course (learners) | PNG, JPG or PDF | 10 MB |
| Payment proof for your Atlas plan | PNG, JPG or PDF | 10 MB |
| Support ticket image | PNG, JPG, GIF or WebP | 10 MB |
| Assignment attachment (learners) | PDF or image (JPG, PNG, GIF, WebP) | 10 MB |

## Why a file was refused

- **Wrong type.** Atlas reads the file itself, not its name. Renaming a file (for example from `.docx` to `.pdf`) does not change what it is, so it is still refused. Save or export it in an accepted format instead.
- **Too large.** Make the image smaller or export the PDF at a lower quality, then try again.
- **Storage full.** Uploads also count toward your plan's general storage. When it is full, new uploads are refused until you free up space or upgrade. See [Plan limits reference](doc:DOC-REF-001).

## Word documents

Word files are not accepted. Save them as PDF first, both for lesson files and for assignment answers.

## Video files

You can't store video files on Atlas. Video lessons are YouTube videos or links to another site. See [Add a YouTube video lesson](doc:DOC-LRN-006).

> [!NOTE]
> A lesson file uploaded in the course builder can be opened only by learners enrolled in that course, through a link that expires. A file you link to on another site can be opened by anyone who has that link.
