**Academy Media** is your academy's file library. The same library opens as
**Media Library** when you pick an image inside the website editor, the
course settings or the certificate template.

Owners and managers can upload and delete. Instructors can browse and pick
files but not upload or delete them.

## Upload and manage files

1. In the dashboard, open your academy and choose **Academy Media** in the sidebar.

   ![The academy dashboard with Academy Media highlighted in the sidebar](shot:protection/media-nav)

2. Choose **Upload** and pick a file from your computer. The progress shows **Uploading**, then **Upload completed successfully**.

   ![The Academy Media page with the Upload button highlighted](shot:protection/media-upload)

3. Choose a file to open **File details**. For an image, fill in **Alt text** (it describes the image for screen readers) and choose **Save changes**.

   ![The File details dialog with the Alt text field highlighted](shot:protection/media-details)

4. Use **Search files** to find a file, the **Status** filter, and **Grid view** or **List view** to change the layout.

   ![The Academy Media page with the Search files box highlighted](shot:protection/media-search)

5. To delete a file, open it and choose **Delete**, then confirm. To delete several, choose **Select**, tick the files and choose **Delete selected**.

   ![The delete confirmation for a media file](shot:protection/media-delete-confirm)

## Supported files

JPG, PNG, GIF, WebP and PDF. Atlas checks the file's real content, not just
its name: anything else is refused with "That file type isn't supported."
Video files are refused too; video lessons use YouTube links. Size limits:
[Supported files and size limits](doc:DOC-REF-002). Library storage counts
towards your plan ([Pricing](site:/pricing), [Plan limits](doc:DOC-REF-001)).

Atlas doesn't resize images or make thumbnails: upload images at the size
you need.

## Deleting files

A file that is still used by a lesson, course, page or logo can't be
deleted. The message names where it is used: replace or remove it there
first, then try again. A deleted file leaves your library at once, but the
file itself isn't erased from storage straight away, and the dashboard
doesn't show when it is.

## Who can see your files

> [!LIMITATION]
> What the media library does **not** protect:
>
> - Files used on your **public website**, such as the logo, course covers,
>   certificate template logo and images on your pages, are **public**:
>   anyone with the file's address can open them, without signing in.
> - Other files you upload here, even ones you haven't used anywhere yet, can
>   also be opened by anyone who has their address.
> - The watermark and device limits apply to lesson videos, not to library
>   images or PDFs.
> - Deleting a file doesn't make its address stop working right away: a page
>   or link that already uses it may still open the file.
> - Deleting a file doesn't remove the copies kept in Atlas's backups.
>
> Don't upload private documents, answer keys or personal data to the library.
